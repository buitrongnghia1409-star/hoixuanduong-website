Quản lý nội dung website

Sửa hero, slogan, dịch vụ, ưu đãi, sản phẩm, cơ sở và FAQ từ một file dữ liệu duy nhất.

Cách dùng nhanh

  1. Sửa nội dung trong từng nhóm bên phải.
  2. Bấm “Thêm mục” nếu cần thêm dịch vụ, hero, chi nhánh...
  3. Bấm “Tải file dữ liệu”.
  4. Thay file website/assets/data/site-data.json bằng file vừa tải rồi push lên GitHub.

Trang này không lưu trực tiếp lên server để tránh sửa nhầm. Dữ liệu chỉ được xuất ra file JSON.
